# Blog Management System - Project Documentation

## 1. Project Overview

The Blog Management System is a Full Stack Development project created as part of my internship.

The application allows users to create, view, update, and delete blog posts through a simple and responsive user interface.

## 2. Project Objectives

- Understand frontend and backend development
- Build REST APIs using Express.js
- Implement CRUD operations
- Connect frontend and backend using Fetch API
- Practice Git and GitHub
- Build a responsive user interface

## 3. Technologies Used

Frontend:
- HTML5
- CSS3
- JavaScript
- Fetch API

Backend:
- Node.js
- Express.js

Tools:
- VS Code
- Postman
- Git
- GitHub

## 4. Features

### Add Blog
Users can create a new blog by entering the blog title and author.

### View Blogs
All available blog posts are displayed on the website.

### Edit Blog
Users can update existing blog posts.

### Delete Blog
Users can delete unwanted blog posts.

### Responsive Design
The website is optimized for desktop, tablet, and mobile screens.

## 5. REST API Endpoints

GET /blogs
- Retrieves all blog posts.

POST /blogs
- Creates a new blog post.

PUT /blogs/:id
- Updates an existing blog post.

DELETE /blogs/:id
- Deletes a blog post.

## 6. Frontend-Backend Integration

The frontend communicates with the Express.js backend using the JavaScript Fetch API.

The frontend sends HTTP requests to the REST API and dynamically displays the returned blog data.

## 7. Project Outcome

Through this project, I gained hands-on experience with CRUD operations, REST APIs, Express.js, Fetch API, responsive web design, Git, and GitHub.

The project helped me understand how frontend and backend components work together in a Full Stack web application.
