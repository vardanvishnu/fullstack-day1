# Blog Management System

A Full Stack Blog Management System developed as part of my Full Stack Development Internship.

## Features

- Add new blog posts
- View all blog posts
- Edit existing blogs
- Delete blogs
- Responsive design
- Frontend and backend integration
- REST API implementation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Node.js
- Express.js
- REST API
- Git & GitHub
- Postman

## API Endpoints

- GET /blogs - View all blogs
- POST /blogs - Add a new blog
- PUT /blogs/:id - Update a blog
- DELETE /blogs/:id - Delete a blog

## How to Run the Project

1. Clone the repository
2. Install dependencies:

npm install

3. Start the Express server:

node index.js

4. Open index.html using Live Server.
